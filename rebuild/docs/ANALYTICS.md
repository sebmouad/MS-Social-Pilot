# Analytics ingestion and coverage

The single `/analytics` view sums the latest stored audience value once per selected channel and displays every stored Page metric and account-level advertising metric in the chosen range. Audience is a cross-channel sum, not deduplicated people. Publishing counts now use the same selected channels and range. Published items use `publishedAt`, scheduled items use `scheduledAt`, and failed items use `createdAt`.

Facebook Page ingestion reads the Root-managed `meta.pageInsightMetrics` list. The default requests follows, media views, post engagements, and Page views; Root can change the list without editing code. Every dated value returned by Graph is stored under its own metric, provider period, and `end_time`. Numeric values and JSON breakdowns are retained. Repeating a sync updates the same observation rather than creating a new point under the sync date. Disabled Facebook engines do not run Page, Ads, or Inbox sync jobs.

Provider support still requires live validation against this installation's approved scopes and API version. A rejected metric currently fails the combined Page Insights request, so Root must remove unsupported entries; per-metric failure isolation and visible sync diagnostics remain to be built. Page sync reads one Graph response and does not yet follow Insights pagination. Advertising sync is account-level; campaign, ad-set, and ad-level analytics remain incomplete. Other platform adapters and channel types do not yet contribute insights.
